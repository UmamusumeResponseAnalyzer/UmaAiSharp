# 普通训练到建设决策

runtime v12／training-turn v12支持普通训练到建设107的两决策链，触发规则身份为`pioneer-construction-trigger-v3`。

`TrainingTurn.Development`保存行动前的建设状态：当前计划及顺序、六设施、发展Pt、规划预算、deck、发券阈值、当前券数和事件队列。编译检查它与训练状态的回合、阶段、Pt及队列一致；合宿设施也必须一致。SQLite 只在 MCP 加载边界读取，执行器消费已加载规则。缺少该建设状态时保留未知，训练在后续事件窗口停止。

普通成功训练在回合5..60跨过一个本期阈值时，收益、Pt、羁绊和次数按原有顺序结算，然后揭示事件211067／故事400011107／角色0／时机6。回合保持不变，协议阶段进入5。设施和券数此时尚未改变；同次训练触发的等级升级留在`PendingTrainingLevelCommandId`。

选项0使用既有建设结算：按有序计划的累计master边成本，与已经达到的发券阈值比较，应用可完成的设施前缀；票数分量要求已知前态0或1，结算后为1。当前券数的输入类型允许非负值和未知，终盘实包中的2张券可以完整保留，不能把建设局部适用条件当作全局持有上限。

自主训练跨阈值时直接结算设施与券，再按更新后的设施状态生成下一训练面板。条件回放保留建设确认，分量回放在 `ConstructionRemainderUnknown`（1007）停止并返回已提交的设施与券。

MCP 导入也支持当前已经可见的107／108建设事件。三个识别身份为211067／107／时机6、211076／107／时机10、211068／108／时机1，角色均为0。训练生成路径只安排第一种身份；比赛／Tucker的时机10及合宿延后108沿用各自的待处理边界。
