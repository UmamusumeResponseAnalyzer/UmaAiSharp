# 执行引擎与 Pioneer 性能基准

使用 Release 构建 `benchmarks/UmaAiSharp.Benchmarks`。基准要求 x64／AVX2，显式比较 AVX-512 的复制项目还需要该指令集。

| 基准 | 测量范围 |
| --- | --- |
| `TrainingBenchmarks`、`IslandTrainingBenchmarks` | 以现行精确参考核为对照，比较紧凑数值核及预编译卡组。初始化核对普通层和剧本层的实际增量。 |
| `Execution*Benchmarks` | 普通／合宿失败实包的初始编译、复制、分叉、两步执行及 64／4,096 样本。报告单位为失败片段。 |
| `TrainingTurn*Benchmarks` | 当前训练行动的预览、单步结算和批量执行。 |
| `ConstructionBenchmarks`、`PlacementBenchmarks` | 建设配置编译、建设单步和完整片段，以及不同 NPC 人数下的人员板生成。 |
| `CopyBenchmarks`、`IslandCopyBenchmarks` | 复制算子和复用工作区的状态复制。 |

夹具在计时外加载和核对。全量基准所需的本地实包投影见 [README](../README.md#本地验证材料)。冷编译、即时执行与大批量调度分开计量。

## 复跑

```powershell
$bench = 'benchmarks/UmaAiSharp.Benchmarks/bin/Release/net10.0/UmaAiSharp.Benchmarks.dll'
dotnet $bench --filter '*TrainingBenchmarks*' '*IslandTrainingBenchmarks*' --exporters json --artifacts '<新目录>'
$env:DOTNET_TieredCompilation = '0'
dotnet $bench allocation-check '<新报告.json>'
dotnet $bench profile ordinary '<新报告.json>'
dotnet $bench profile camp '<新报告.json>'
dotnet $bench profile island '<新报告.json>'
```

`profile` 比较 64／4,096 个片段在 1／2／4／8／16／32 worker 下的结果校验和。64 个片段共用一个工作区。自主整局的 `pioneer_batch` 按样本数和请求的 worker 数分配工作区。报告包含累计托管分配、耗时、GC 次数和进程内存峰值。进程内存峰值也包含程序启动和夹具加载。

对完整育成搜索计时，可通过 [Pioneer MCP](pioneer-mcp.md#根候选推荐) 固定实包锚点、规则指纹、模型、目标、种子、首批样本与 worker 数。先对照排名、逐样本终局、停止位置和 RNG 末态，再比较耗时。报告保留实际加样后的样本量。

## 2026-11-22 五轮对照

基线为 `84f0aeb`。在 Ryzen 9 9950X3D（32 个逻辑处理器）、Windows x64、.NET 10.0.15 Release 下，基线和优化版每轮交换先后顺序，表中取各自五轮中位数。微基准直接调用已有基准方法，夹具加载、断言和预热均在计时外。下表微基准及 21／72 回合的 MCP 对照均设置 `DOTNET_TieredCompilation=0`。

| 工况 | 基线耗时 | 优化后耗时 | 托管分配（基线 → 优化后） |
| --- | ---: | ---: | ---: |
| 新进程首次编译普通失败片段与脚本 | 94.94 ms | 92.40 ms | 41,328 → 39,568 B |
| 新进程首次编译合宿失败片段与脚本 | 96.36 ms | 99.16 ms | 46,520 → 43,416 B |
| 已预热的普通训练配置编译 | 24.28 μs | 21.27 μs | 33,336 → 31,576 B |
| 普通训练行动预览 | 2.65 μs | 2.07 μs | 640 → 352 B |
| 普通空板，预编译数值核 | 2.60 μs | 1.40 μs | 664 → 184 B |
| 合宿行动单步 | 5.32 μs | 5.08 μs | 1,504 → 960 B |
| 岛训练片段（1058） | 5.51 μs | 4.35 μs | 1,528 → 888 B |
| 岛训练片段（3298） | 5.62 μs | 5.35 μs | 1,528 → 1,080 B |
| 建设完整片段（门槛 200） | 3.24 μs | 2.59 μs | 736 → 384 B |
| 12 个 NPC 的人员板 | 600 ns | 492 ns | 0 → 0 B |
| 第 21 回合跑到终局，精确，64 样本／8 worker | 919.35 ms | 111.31 ms | 253.73 → 158.56 MB |
| 第 21 回合跑到终局，快速，64 样本／8 worker | 144.53 ms | 21.99 ms | 31.38 → 31.43 MB |

整局两行计入执行与调度，MB 按 1,000,000 B 计。精确模型的每次普通训练计算减少了大整数分配；64 条完整轨迹由 1 个工作区增加到 8 个，单条轨迹的随机种子和结果槽由样本编号决定。复用目标工作区时，普通状态复制约 11 ns，精确分叉约 14 ns，两者均为 0 B。

32 个 worker 执行 4,096 个岛训练片段时，并发扫描末档的中位数从 1.72 ms 升至 3.26 ms。终版五次计时窗口均发生一代 GC，基线五次均没有。在独立进程中连续执行，每版测十组、每组 64 批，平均每批耗时的中位数为 2.09 → 2.17 ms（+3.9%）。

第 72 回合面板有 12 个候选，每个候选完成 32 条轨迹。精确推荐的 MCP 往返从 129.71 ms 降至 120.87 ms，快速推荐为 84.30 ms 和 84.59 ms。相同抓包的导入分别为 1.54 s 和 1.59 s，主要读取 691 个育成历史包和 12 个继承档案响应。这一工况的整条链路仍以导入耗时为主。

单独重放该面板的 384 条终局数据，终版计算五维评分耗时 82.59 μs，汇总 12 个候选耗时 18.16 μs，对候选摘要排序耗时 0.68 μs。

第 38 回合合宿推荐使用 .NET 默认分层编译和 16 个 worker。两种模型都从每候选 1 条加样到 2,048 条，一次推荐共 22,528 条。精确推荐的 MCP 往返中位数为 12.69 s 和 12.57 s，搜索期间累计托管分配从 60.55 GB 降至 37.07 GB。快速推荐为 3.73 s 和 3.80 s。两版耗时区间重叠，各模型的排名、逐样本终局及 RNG 末态在五轮中一致。

另试过对六张预测板中的相同人员组合复用训练预览。第 21 回合的五轮独立对照中，精确执行耗时下降 3.5%，快速执行耗时增加 4.3%，因此撤回了这项改动。

本次的本地报告位于 `artifacts/performance/pioneer-five-rounds-20261122/verified/performance.md`。同目录的 `performance.json` 保留逐轮耗时、分配、校验和及整局对照指纹。

## 途中继承逐面板积分的基线

使用四个完整六来源谱系面板，各以 65,536 次随机抽选作为模型参照。每次保留获胜候选各因子的原始属性点，并按当时上限裁剪。这组基线使用 1,024 个固定积分点，再用连续 2,048 个配对样本编号验证整数兑现。下表为单次继承的均值 ± 标准差。

| 实包、继承回合 | 五维原始增量，抽选 → 期望兑现 | Hint 总等级增量，抽选 → 期望兑现 |
|---|---:|---:|
| #1269，31，Uma Plan | 179.75 ± 41.53 → 180.38 ± 1.02 | 54.54 ± 11.61 → 54.49 ± 2.46 |
| #1489，55，Uma Plan | 191.20 ± 41.81 → 191.56 ± 1.57 | 42.44 ± 10.01 → 42.30 ± 2.35 |
| #2364，55，普通 | 30.03 ± 13.93 → 30.07 ± 0.84 | 0 → 0 |
| #36413，55，普通 | 65.26 ± 21.07 → 65.20 ± 1.32 | 2.57 ± 2.11 → 2.57 ± 1.00 |

相同进程设置下交错运行五轮（Windows x64、Release、关闭分层编译、种子 12345、8 个工作区）。每批 256 条轨迹，精确模型从 #1269 至终局的往返中位数为 455.7 → 491.3 ms，从 #1489 为 209.8 → 234.7 ms，从普通面板 #36413 为 189.1 → 184.3 ms。快速模型在 #1489 用 17 个候选完成整次推荐，两版各运行 15,872 条轨迹，首位均为行动 701，耗时为 3.280 → 4.028 s。该面板精确模型整局总评分标准差为 1252.9 → 1255.8。

四个面板的继承技能 Pt 和属性溢出增量都为零，非零结算由定向用例验证。逐维、逐 Hint、实际选组和五轮原始数据见本地 `artifacts/performance/pioneer-inheritance-20261122/verified-inheritance.md`。[结算口径](base-mechanics.md#hint继承与路线)

## 固定谱系解析期望

每次编译育成面板时计算谱系期望，第 31、55 回合以及所有行动分支共用。以下结果来自同一完整谱系实包 #1489，Windows x64、.NET 10 Release、关闭分层编译、种子 12345、8 个工作区。三版预热后轮换执行五轮，取各自中位数。

| 快速模型 | 256 条轨迹的批量往返 | 完整推荐往返 | 推荐服务内执行 |
|---|---:|---:|---:|
| 逐轨迹随机抽选 | 101.37 ms | 3.471 s | 3.372 s |
| 逐面板积分 | 122.48 ms | 4.016 s | 3.917 s |
| 固定谱系解析期望 | 95.68 ms | 3.275 s | 3.184 s |

三版均比较 17 个行动、运行 15,872 条轨迹，首位均为 701。解析版的完整推荐比积分版快 18.5%，比逐轨迹随机版快 5.7%。精确模型另以四个面板各跑五轮。两个 Uma Plan 面板的 256 条轨迹批量往返分别减少 3.5% 和 11.6%，两个普通面板的中位数增加 0.35% 和 2.0%。

每个面板另按固定原始分独立抽选 262,144 次，以校验普通单候选和 Uma Plan 双候选的收益。四个实包中，五维原始收益均值的最大差为 0.072 点，单项 Hint 等级均值的最大差为 0.007 级。当前属性上限按原始期望统一裁剪，实包覆盖范围与逐项数据见本地 `artifacts/performance/pioneer-fixed-expectation/verified.md`。[期望与兑现口径](base-mechanics.md#hint继承与路线)
