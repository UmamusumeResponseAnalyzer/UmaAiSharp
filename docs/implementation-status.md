# Pioneer 实施状态

本机 stdio `UmaAiSharp.MCP` 提供 25 项工具。导入、执行、回放、批量和推荐使用同一份规则资源。规则来自离线 master 与实包校准，PioneerAiPlugin 将其嵌入 ZIP。工具与配置见 [MCP 接入](mcp.md) 和 [构建说明](../README.md#工程边界)。

## 自主模拟

从开局或可恢复的中途面板生成合法行动。训练、休息、出行、岛训练、建设、评审、两次继承、比赛及结局共用同一场景。训练与建设在 URA 提供整局建议，单候选按终局达标率和达标样本的总分评价。路线失败计入终局，机制停止在报告中记录动作位置及原因。 [执行与推荐](pioneer-mcp.md)

训练就绪和建设规划面板按整局结算推荐。缺少开局亲本时只省略剩余继承，部分卡牌固有、赛程条件和事件分支缺少依据时保留已确认的收益。训练面板、建设面板和 MCP 报告列出对应编号。条件回放要求与实际动作匹配的结果。已揭示的多选事件按当前目标比较即时奖励，未提供概率的分支逐一比较。

## 规则依据

- 训练时保留当前实包的人员板、指令和等级。未来的人员分配、Hint、失败后果的概率以及部分事件奖励来自已记录的拟合和先验。 [训练公式](training-formula-evidence.md) · [人员分配](joint-placement.md)
- 继承在第 31、55 回合抽取完整因子效果，依赖开局冻结的亲本和祖辈。校准报告按因子分层记录拟合与留出机会。 [开局与继承证据](initial-inheritance-evidence.md)
- 比赛按第一名结算，可选赛也参与推荐。已确认的目标赛追加奖励按路线、状态与战绩结算。部分额外奖励及低档评审来自有限样本。 [比赛证据](race-route-evidence.md) · [评审证据](checkpoint-evidence.md)
- 技能使用终局可购评分增量估计。模型范围排除赛中名次模拟、购技动作、技能进化及终局因子抽取。 [终局证据](terminal-evidence.md)

## 校验范围

日服 master（SHA-256 `95f14e3b83d469d0a22abecdcbc21d194db59f5986e01c195130f9424269e234`）含 136 名育成角色、276 张育成卡及 568 张支援卡，其中普通卡 538 张、友人卡 25 张、团卡 5 张。本地五个 SQLite 库提取了 18,430 个无待确认事件的训练或建设面板。按衣装、六张编成卡和行动阶段去重得到 206 组，实际涉及 47 张育成卡和 30 张支援卡。每组固定种子抽取一份原响应，经 `pioneer_import_packet` 导入，再经 `pioneer_run` 运行一条轨迹，206 组均到达终局。样本覆盖第 1–77 回合。该口径检验可执行性，逐回合准确度需另用观测结果对照。

中山庆典 30108 的固有 112 使用真实第 46 回合面板换卡对照：精确和快速模型各 1,024 个种子。她参与且原失败率非零的 914 个未来训练有 182 个归零，4,193 个未参与训练均与对照一致。当前包显示的 8% 得到保留。

568 张支援卡另做了逐卡覆盖检查。每次从第 48 回合真实规划面板替换一个卡位，按 master 写入同卡位角色及该稀有度满级经验，并避开与育成角色及其余编成重名。每张卡经单包导入和单条固定种子模拟抵达终局。换卡样本验证卡片编译、忽略提示和后续结算；原始实包出现过的支援卡数量以 30 张计。
