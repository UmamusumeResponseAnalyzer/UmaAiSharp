# Pioneer 实施状态

本机 stdio `UmaAiSharp.MCP` 提供 25 项工具。导入、执行、回放、批量和推荐使用同一份规则资源。规则来自离线 master 与实包校准，PioneerAiPlugin 将其嵌入 ZIP。工具与配置见 [MCP 接入](mcp.md) 和 [构建说明](../README.md#工程边界)。

## 自主模拟

从开局或可恢复的中途面板生成合法行动。训练、休息、出行、岛训练、建设、评审、两次继承、比赛及结局共用同一场景。训练与建设在 URA 提供整局建议，单候选按终局达标率和达标样本的总分评价。路线失败计入终局，机制停止在报告中记录动作位置及原因。 [执行与推荐](pioneer-mcp.md)

推荐在训练就绪或建设规划面板开始。育成数据缺项时，只要求实际结算所需的输入，例如尚未发生的继承需要亲本资料，未结束的累计比赛目标需要本局战绩。缺少已获取的训练历史可按当前等级和执行次数估计。条件回放仍须提供与实际动作匹配的结果。模拟遇到缺失机制时，面板显示具体原因和有记录的回合。

## 规则依据

- 训练时保留当前实包的人员板、指令和等级。未来的人员分配、Hint、失败后果的概率以及部分事件奖励来自已记录的拟合和先验。 [训练公式](training-formula-evidence.md) · [人员分配](joint-placement.md)
- 继承在第 31、55 回合抽取完整因子效果，依赖开局冻结的亲本和祖辈。校准报告按因子分层记录拟合与留出机会。 [开局与继承证据](initial-inheritance-evidence.md)
- 比赛按第一名结算，可选赛也参与推荐。已确认的目标赛追加奖励按路线、状态与战绩结算。部分额外奖励及低档评审来自有限样本。 [比赛证据](race-route-evidence.md) · [评审证据](checkpoint-evidence.md)
- 技能使用终局可购评分增量估计。模型范围排除赛中名次模拟、购技动作、技能进化及终局因子抽取。 [终局证据](terminal-evidence.md)

## 校验范围

条件回放可逐步比较资源、羁绊、等级、阶段与待处理故事。实包对照只覆盖有明确观测的行动与奖励。固定种子对照可检验契约变更或优化是否影响已有路径。整局推荐的质量与未选动作收益只能在另外指定的评估口径下判断。 [回放输入](pioneer-mcp.md#训练后事件条件回放) · [性能与路径复跑](engine-performance.md)
