# 训练预览结算证据

`TrainingPreviewSettlement` 合并已经给出的普通训练预览与 Pioneer 附加预览，结算五属性、体力和技能 Pt。它不生成预览，不处理失败、事件、人员分配或回合推进。

运行核验：

```powershell
dotnet run --project src/UmaAiSharp.Cli -- evidence training --input artifacts/evidence/local-audit-05 --output artifacts/evidence/training-audit-new
```

输出目录必须为空。`training-audit.json` 保存输入文件哈希、筛选计数、排除原因与适用范围；`training-transitions.jsonl` 保存每个适用转移的来源、请求/响应位置、预览、预测值及观测值。输入来自正式 `evidence audit` 生成的动作与观测文件。

最终实包核验报告位于 `artifacts/evidence/training-audit-04/training-audit.json`，同时固定观测、动作和请求响应关联三个输入文件的哈希。

核验只接纳以下转移：相邻观测有相同且明确的 actor+run 身份；请求响应关联为 `Paired` 且明确包含所用请求、响应引用；请求唯一且按同源捕获顺序位于前后响应之间；请求回合、体力与前置快照一致；选择的训练在 home 和顶层 Pioneer 数据中都有完整预览；结果类型为观测到的 `result_state=2`；前后属性和体力上限相同。空数组表示该段没有增量，缺失或 null 不能替代为空数组。请求与前置快照不一致时，不把响应净差归因于训练。

本地 `local-audit-05` 的 3951 条 exec_command 响应中，3143 个转移通过以上条件，五属性、体力和技能 Pt 全部匹配。其中 114 个转移发生体力上限截断。另有 779 条非训练指令、17 条旧快照、4 条缺失或歧义请求、4 条相邻身份不明及 4 条缺失预览，均不进入适用样本。匹配样本中，2403 条响应回合不变，740 条增加一回合；此模块不根据训练动作自动增加回合。

观测的前后数值范围如下，最小值到最大值之间并非每个输入组合都已验证：

| 参数 | 最小值 | 最大值 |
|---|---:|---:|
| speed | 92 | 1882 |
| stamina | 84 | 1508 |
| power | 67 | 1750 |
| guts | 69 | 1384 |
| wiz | 90 | 1313 |
| vital | 27 | 112 |
| skill_point | 120 | 4098 |

这些样本没有验证属性上限截断或体力下限截断；对应输入会明确失败。预览是否已经发生过属性截断也未得到证明，因此本模块不输出“原始训练收益”或累计属性溢出，不能把缺少溢出证据记作零。未观测的结果类型、训练失败概率、训练收益生成及事件效果仍需独立实现和验证。

该核验采用本地材料；文件哈希与捕获版本用于追溯，不要求严格版本绑定。全部适用局部转移匹配，不等于完整育成轨迹或训练引擎已经完成。
